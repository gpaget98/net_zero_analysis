# net_zero_perspective_analysis

Analysis of net-zero climate changes over Australia to contribute to net-zero perspective piece. 



This project is structured as following:

```bash
net_zero_perspective_analysis/
├── analysis
│   ├── example.ipynb
│   └── figures
│       └── .figures
├── .copier-answers.yml
├── data -> /g/data/ng72/$USER/net_zero_perspective_analysis/data
│   ├── derived
│   └── raw
│       └── DO_NOT_EDIT
├── .envrc
├── .git
├── .gitignore
├── README.md
├── requirements.txt
├── src
│   └── net_zero_perspective_analysis
│       ├── __init__.py
│       └── sample_fun.py
└── tests
    └── net_zero_perspective_analysis
        └── test_sample_fun.py
```

The data folder may not be present in the repository but instructions and or documentation are provided.
